# PALADINO — MCP TEST 02
## 10-slide presentation brief for Claude + Figma MCP

### Objective

Create a 10-slide presentation in Figma using the existing **TMS Marketing** presentation system as the visual source.

This is a workflow test, not a final Paladino presentation.

The objective is to validate whether Claude can:

1. understand a strategic narrative;
2. select appropriate existing layouts;
3. reuse the Figma system instead of inventing a new one;
4. preserve the logic of the source content;
5. produce a presentation that remains editable and structurally clean inside Figma.

### Important constraints

- Do **not** redesign the visual language.
- Do **not** create a new design system.
- Prefer existing TMS Marketing layouts, components, styles and patterns.
- Preserve typography, spacing, grid and hierarchy from the source file.
- Do not create unnecessary new components.
- Do not simplify the content into generic branding language.
- Do not invent Paladino claims beyond what is provided here.
- Keep the tone concise, conceptual and direct.
- Prioritize editorial clarity over decoration.
- If a requested structure does not exist in the template, choose the closest existing layout rather than creating a new visual language.
- Keep all generated slides fully editable in Figma.
- Use Portuguese for this test.
- Images are optional. If a layout requires an image and no relevant asset is available, use an existing neutral placeholder from the template rather than searching for a new visual direction.

# EXECUTION LOGIC

Before creating the slides:

1. Inspect the available layouts in the connected TMS Marketing Figma file.
2. Identify the existing layout that best matches each slide brief.
3. Reuse existing components and styles whenever possible.
4. Do not create the full presentation until you have mapped each slide to an existing layout.
5. If possible, provide a short mapping before execution in this format:

| Slide | Recommended existing layout | Reason |
|---|---|---|
| 01 | [layout/frame] | Cover |
| 02 | [layout/frame] | Statement + supporting list |
| ... | ... | ... |

Then create the 10 slides in a new section/page dedicated to this test.

Suggested name:

**PALADINO — MCP TEST 02**

After creating the slides, review the generated Figma structure and report:

- which existing layouts were reused;
- which components were reused;
- whether any new components or styles were created;
- any limitation encountered;
- any slide where the content did not fit the selected template cleanly;
- what you would change in the source content or presentation grammar before the next test.

# SUCCESS CRITERIA

The experiment is successful if:

- the Paladino argument remains recognizable and specific;
- the presentation feels like it belongs to the existing TMS system;
- slides use appropriate structures for their content;
- generated frames remain clean and editable;
- there is little or no unnecessary duplication of components;
- Claude can explain the decisions it made;
- the result can be refined manually rather than rebuilt from scratch.

The objective is not visual perfection.

The objective is to validate a repeatable workflow:

**strategic content → narrative structure → existing layout selection → Figma execution → human refinement**
